# HTML, CSS & JavaScript Basics Project

This is a deliberately simple project designed for learning rather than production.

## Files

- `index.html` — page structure
- `style.css` — page appearance
- `script.js` — behaviour and interaction

## How to run it

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Open it in a browser.
4. If you use VS Code, you can install the Live Server extension and open `index.html` with Live Server.

## How to study this project

Do NOT just read the annotations.

Use this process:

### Stage 1 — Read

Read one section and make sure you understand what it does.

### Stage 2 — Hide

Comment out or delete the section.

### Stage 3 — Rebuild

Try to recreate it from memory.

### Stage 4 — Change it

Change something yourself.

Examples:

- Change colours
- Add another button
- Add another section
- Add a new task feature
- Change the counter
- Add a "Clear all" button

### Stage 5 — Break it

Intentionally change something and see what happens.

Then use the browser developer console to find the error.

## Challenge

Once you understand the project, try to build the following without looking at the original:

1. A counter
2. A task list
3. A form
4. A responsive layout
5. A button that changes something on the page

Then combine them into one project.

That is where the real learning happens.
